## Brand & Style

This design system delivers **calm industrial confidence** tailored for high-stakes enterprise procurement, scrap commodities, and surplus asset disposition. In a market where transactions involve lakhs of rupees, heavy freight logistics, and inherent material uncertainty, the interface functions not as an energetic consumer marketplace, but as an institutional settlement terminal.

The aesthetic fuses **Corporate Utility** and **Constructivist Precision**:
- **Tone**: Authoritative, methodical, and disciplined. It eliminates visual noise, decorative gradients, and ephemeral styling in favor of high-legibility density and verifiable data.
- **Target Audience**: Plant heads, industrial scrap liquidators, certified recycling syndicates, and corporate salvage procurement executives.
- **Visual Stance**: Structured flat white surfaces resting over a cool institutional canvas, anchored by hairline architectural dividers and deep teal governance tones. Vibrant orange is rationed strictly to irreversible auction actions.

## Colors

The color architecture enforces operational discipline through clear semantic boundaries:

- **Primary Teal (`#0F4C5C`)**: Represents institutional authority, structural framing, and verified status. Applied to navigation infrastructure, table headers, verified badges, and trust-confirmation elements.
- **Action Orange (`#BD5418`)**: Reserved exclusively for high-stakes primary bid actions and transactional commitments ("Place Bid", "Pay EMD", "Publish"). Its use is strictly rationed to at most one prominent primary element per viewport.
- **Accent Orange (`#E8772E`)**: A non-text decorative marker used strictly for the pulsating live auction indicator dot and stepper progress pins. Never used as a foreground text color.
- **Neutral Architecture**: Clean white surfaces (`#FFFFFF`) layered over an engineered grey canvas (`#F7F8FA`). Structural definition is achieved with precise hairline outlines (`#E2E8F0` and `#CBD5E1`) rather than blurred drop shadows.
- **Lot Assurance Trust Tiers**:
  - *Tier 1 (Seller Declared)*: Neutral grey backing (`#F1F4F7`) with slate foreground (`#334155`). Indicates unverified self-reporting.
  - *Tier 2 (Evidence Attached)*: Clean white backing (`#FFFFFF`) with deep slate teal text (`#145466`) and a crisp teal border (`#1C5F6D`). Indicates uploaded weighment or photo evidence.
  - *Tier 3 (Confirmed at Lifting)*: Solid teal fill (`#0F4C5C`) with pure white text (`#FFFFFF`). Indicates certified weighbridge physical confirmation.

## Typography

The design system uses **Inter** across all typographic applications. 

- **Tabular Numerics (`tnum`)**: All pricing metrics, bid ladders, currency counters, weights in metric tons, and countdown timers must enforce `font-feature-settings: 'tnum' 1`. This prevents layout jitter during real-time auction recalculations.
- **Overline / Eyebrows**: Set at 11px uppercase with positive letter spacing (`0.06em`) for table headers, metadata descriptors, and stat labels.
- **Hierarchy Rules**: Display scale is reserved exclusively for unauthenticated landing views. In-app work surfaces rely strictly on `headline-lg` down to `caption` to maintain maximal data density.

## Layout & Spacing

A strict **4px/8px incremental grid** governs density and data alignment:

- **Desktop Framework**: 12-column grid capped at 1280px max-width, with 24px gutters and margins.
- **Work Surface Splitting**:
  - *Catalogue Views*: 280px fixed filter rail paired with a 3-column card grid (24px gap).
  - *Lot Detail Split*: 65% primary evidence pane alongside a 35% sticky procurement desk (fixed at 384px width, anchored 88px from the top).
  - *Forms & Workflows*: Single-column, center-aligned, constrained to 560px max width with 24px vertical separation between control blocks.
- **Responsive Behavior**:
  - *Mobile (<768px)*: The 240px vertical sidebar collapses into a persistent bottom navigation bar. Sticky bid consoles transform into a fixed mobile action tray with a single tap action. Layout gutters tighten from 24px (`space-lg`) to 16px (`space-md`). Table structures convert into modular card stacks.

## Elevation & Depth

Visual hierarchy relies on **crisp tonal separation and low-contrast borders** rather than diffuse shadows.

- **Level 0 (Flat Ground)**: Baseline cards, tables, canvas sections, and input fields feature zero box-shadow. They derive structure from a 1px solid hairline border (`#E2E8F0`).
- **Level 1 (Subtle Focus / Hover)**: Used for active list row hovers and the sticky desktop bidding console:
  `box-shadow: 0 1px 2px 0 rgba(15, 23, 42, 0.06)`.
- **Level 2 (Popovers / Trays)**: Used for select dropdown menus, contextual flyouts, and mobile bottom trays:
  `box-shadow: 0 4px 12px 0 rgba(15, 23, 42, 0.08)`.
- **Level 3 (Modal Dialogs)**: Reserved strictly for settlement dialogs, bid confirmations, and critical error alerts:
  `box-shadow: 0 12px 32px 0 rgba(15, 23, 42, 0.12)`.
- **Scrim Backdrop**: Modals must deploy a flat structural scrim using `rgba(15, 23, 42, 0.40)`. Ambient blur filters are prohibited to preserve clear text contrast behind overlays.

## Shapes

The interface balances sharp industrial geometry with ergonomic utility:

- **Base Radii (`roundedness: 2`)**: Interactive form inputs, buttons, select containers, and toast banners take an 8px (`0.5rem`) corner radius.
- **Card & Panel Radii (`rounded-lg`)**: Structural cards, lot panels, image galleries, and modal containers use 12px (`0.75rem - 1rem`) radius to contain dense tabular content cleanly.
- **Micro Badges (`rounded-sm`)**: Lot Assurance tier badges, compliance certificates, and quantitative property pills use 4px (`0.25rem`) radius to convey rigid documentation.
- **Full Radius (`rounded-full`)**: Preserved exclusively for live state indicators, demo mode identifiers, and pill filters.
- **Media Ratios**: Lot hero photography must maintain a strict 16:10 aspect ratio; gallery inspection thumbnails conform to 4:3.

## Components

### Buttons
- **Primary Action**: Solid `#BD5418` fill, `#FFFFFF` text, 8px radius, height 40px (desktop) or 48px (mobile primary bid). Hover state deepens to `#9A4413`. Only one per layout.
- **Secondary (Governance)**: `#FFFFFF` fill with 1px border in `#1C5F6D`, text `#0F4C5C`. Hover state fills with `#EFF6F7`.
- **Destructive**: Solid `#B91C1C` fill, `#FFFFFF` text. Used exclusively for auction withdrawal or dispute initiation.

### Form Inputs & Controls
- **Input Fields**: Height 40px, `#FFFFFF` background, 1px border in `#7C8A9D`, 8px radius. Text in `#1E293B`, placeholder `#5F6E82`. Focus state activates a 2px outline in `#0F4C5C` with 2px offset.
- **Checkboxes & Radios**: 16x16px boxes with 4px corner radius (checkbox) or circular (radio), `#7C8A9D` border. Active state fills `#0F4C5C`.

### Lot Assurance Tiers (Chips & Badges)
- **Declared Badge (Tier 1)**: Flat `#F1F4F7` background, `#334155` text, 4px radius, prefixed by an outline quote or note icon.
- **Evidence Attached (Tier 2)**: White background, 1px border `#1C5F6D`, `#145466` text, prefixed by an attachment or camera icon.
- **Confirmed at Lifting (Tier 3)**: Solid `#0F4C5C` fill, `#FFFFFF` text, prefixed by a verified scale icon.

### Live Auction Indicators
- **Live Status Chip**: Fill `#FEF4EC`, text `#9A4413`, uppercase 11px font. Features an 8px circular accent in `#E8772E` with a continuous pulse animation.

### Data Tables
- Header height 40px, fill `#F1F4F7`, text `#334155` in 11px uppercase bold.
- Data rows height 48px, 1px horizontal bottom border `#E2E8F0`, alternating with `#F7F8FA` on row hover. All currency and weight columns must right-align with tabular numerals.

### Sticky Bid Panel
- Anchored card component on desktop with 12px radius, `#FFFFFF` fill, 1px `#E2E8F0` border, and Level 1 elevation. Embeds the current leading bid in `price-xl`, minimum bid increment chips, and the primary `#BD5418` action button.
